# uncertainty-calculator
Python-based computational tool for calculating and propagating
measurement uncertainties in laboratory data analysis. This program
supports direct measurements, addition/subtraction and
multiplication/division using quadrature, power and natural logarithm
operations, automatic significant-figure rounding, and basic input
validation. It was further developed based on feedback from Dr. Jesmi
Çavuşoğlu for the Physical Chemistry Laboratory course.

python3 uncertainty_calculator.py
